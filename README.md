## Sobre

O **AXIS Collect** é um sistema web inspirado na experiência de ferramentas de criação de formulários, como o Microsoft Forms.

A aplicação permite criar, configurar, visualizar, salvar, abrir e excluir formulários diretamente pelo navegador.

A proposta do projeto é manter uma arquitetura **simples, pequena e compreensível**, evitando dependências desnecessárias.

## Interface

A identidade visual do AXIS Collect utiliza uma combinação de **branco e diferentes tons de verde**, criando uma interface limpa e moderna.

O projeto utiliza:

- sombras;
- gradientes;
- efeitos de profundidade;
- elementos arredondados;
- efeitos de brilho;
- estados de interação;
- design responsivo.

Tudo desenvolvido utilizando **CSS puro**.
